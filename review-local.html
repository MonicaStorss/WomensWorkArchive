Review before publication

Privacy: This page has no login and must not be put online as a public administrative service. Use it as a local file on your own computer. It does not fetch Formspree submissions automatically or send data anywhere. Load exports from your Formspree dashboard on your computer. Do not put raw submission files or private contact information in your GitHub repository.

1. Import private submissions

Download submissions as JSON or CSV from your form service. For JSON, accepted formats are an array of records, an object with a submissions array, or a previously exported workbench JSON. CSV supports columns named for form fields (person, story, medium, etc.).

No submissions loaded.

2. Review nominations

Submissions start unpublished. Edit public-facing text, classify the record, and expressly confirm permission for publication. The workbench excludes email addresses and private contributor names from the public JSON unless attribution is separately entered.

3. Publish approved records

Upload the generated approved-records.json file into the same GitHub repository folder as index.html, replacing the previous file. GitHub Pages then displays approved records. Replacing the file with the output from this workbench determines the full public set; import the current approved file first if you want to retain earlier publications.

Verification is separate from approval. Assign “Archival record verified” only after confirming documented MIT connection, Distinctive Collections holdings, and a contribution during the late 1960s–2001 research period.
